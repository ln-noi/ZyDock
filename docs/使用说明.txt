ZyDock 使用说明
======================================================================

【0】安装位置很重要（本次唯一需要你注意的事）

    请把整个目录放在**用户目录下**，例如：

        C:\Users\<你的用户名>\Apps\ZyDock\ZyDock.exe

    本次已经装好并创建了桌面快捷方式：
        C:\Users\<你的用户名>\Apps\ZyDock\ZyDock.exe   ← 双击桌面「ZyDock」图标即可

    ⚠ 不要放在受限的工作区/沙箱目录里运行（这类目录会给进程套受限令牌）。
      这台机器对工作区目录下的可执行文件会施加**受限令牌**，症状是：
        · 托盘图标不出现
        · 设置里的「隐藏任务栏」不生效
        · 配置写不进 %APPDATA%，只能落到 exe 同目录 data\ 里
        · 点打包应用（设置/计算器/媒体播放器/终端）失败，
          并且弹出「explorer.exe 应用程序无法正常启动(0xc0000142)」
      把程序放到用户目录后，以上四项全部正常（已实测）。


【1】要运行的是哪个文件？

    双击 本目录下的 ZyDock.exe（或桌面快捷方式）。

    这是「自包含目录版」：.NET 8 运行时就放在本目录里，
    不需要安装 .NET、不需要联网；这个目录版也不会往 %TEMP% 解压。

    判断是否自包含：ZyDock.exe 旁边有 coreclr.dll、hostfxr.dll、
    PresentationFramework.dll、ZyDock.dll。
    ⚠ ZyDock.exe 只有 178 KB，不能单独复制出去；必须整个目录一起搬。


【2】双击后提示「Windows 已保护你的电脑 / 未知发布者」

    SmartScreen 对未签名程序的常规提示。点「更多信息」→「仍要运行」。


【3】双击后弹出「需要安装 .NET」并跳到微软商店

    那是「框架依赖版」（只有 ZyDock.exe + ZyDock.dll + runtimeconfig.json，
    没有 coreclr.dll）。本机只装了 .NET 7，缺 .NET 8 桌面运行时，所以起不来。
    解决：用本目录这个版本；或先装运行时（管理员 PowerShell）：
        winget install Microsoft.DotNet.DesktopRuntime.8


【3.1】关于底板外观

    底板是「清玻璃」：不模糊背景、不取壁纸、没有颗粒噪点，
    只是一层很淡的薄雾 + 发丝描边 + 柔和投影，近乎全透明。
    设置里「背景透明度」默认 30%（5%–92% 可调），觉得太淡就往右调一点。
    「玻璃高光」开关控制顶部高光 / 内侧倒角 / 底部反光。
    「底部阴影」开关控制胶囊下方的柔和投影，关掉后完全平贴桌面。
    「玻璃颜色」可选 6 个预设或直接填 #RRGGBB：
      深色（石墨黑/深空灰）适合深色壁纸；在纯白页面上会显得发黑，
      这时换成「冷银 / 纯白」这类浅色就会变清透。
    「边框粗细」0–3 px，0 表示完全不要边框。
「内边距（左右）」0–80 px、「内边距（上下）」0–60 px，
  控制图标与胶囊边缘之间的留白，觉得挤就往右拉。

    图标下方默认不显示任何小圆点（那个点是"应用是否正在运行"的指示，
    设置 → 外观 → 运行状态指示点 里可以重新打开）。

    【把图标拖进来】
    从桌面/资源管理器把 exe、快捷方式、文件夹直接拖到 Dock 上，
    Dock 会提示"松开即可添加到 Dock"，松手即加入并自动保存。
    同一个目标已经在 Dock 里时会自动跳过，不会重复添加。
    多个文件可以一次全选拖入。

    【调整图标顺序】
    在 Dock 上按住某个图标往左右拖（超过 5 px 才算拖动，所以不会误触，
    单击仍然是启动程序）。拖动时该图标会跟着鼠标走、其他图标让位，
    松手即落位并保存，下次启动顺序不变。

    图标全部取自系统真实资源（程序的 exe 图标、UWP 应用包里的官方 logo），
    不是自己画的；只有系统完全取不到图标时才会用内置矢量图兜底。

    日志：单文件上限 2 MB，超出自动轮转一份（最多约 4 MB），
    纯追加写磁盘、不占内存；正常使用几乎不写日志。
    日志已做脱敏：你的用户目录会写成 %USERPROFILE%，
    文件里不会留下用户名。
【3.2】最大化 / 全屏时自动隐藏

    设置 → 行为 → 「最大化/全屏时自动隐藏」（默认开启）
    只要前台窗口是最大化或全屏（任何软件：游戏、视频、浏览器、Office、资源管理器…），
    Dock 就会完全隐藏，不会浮在窗口上面；窗口还原后自动恢复。
    判定标准是"前台窗口覆盖了屏幕的工作区（任务栏上方那块区域）"，
    所以普通大小的窗口（包括本程序的设置窗口）不会让它隐藏。

【4】日常操作

    · 左键点图标        启动应用 / 打开文件夹 / 打开回收站等
    · 悬停图标          磁吸放大 + 上方显示应用名称
    · 右键图标          打开 / 在资源管理器中显示 / 从 Dock 移除 / 编辑设置
    · 右键 Dock 空白处   弹出 Dock 菜单：打开设置、自动隐藏、隐藏任务栏、开机启动、退出
    · 托盘图标左键      打开设置
    · 托盘图标右键      同上菜单
    · 设置窗口右上角关闭 = 收起到后台继续运行
    · 「退出 ZyDock」   = 真正结束进程，并把 Windows 任务栏恢复原状
    · 再双击一次 exe     = 单实例：唤出已运行实例的设置窗口
    · 自动隐藏开启时，鼠标移到屏幕底边即可唤回


【5】配置与日志

    配置：%APPDATA%\ZyDock\settings.json
    日志：%LOCALAPPDATA%\ZyDock\logs\app.log
    （放在受限目录里运行时会退到 exe 同目录 data\，设置窗口「关于」显示实际路径）

    配置文件损坏会自动备份为 settings.corrupt-<时间>.json 并回退默认。
    想让配置跟着 U 盘走：设置环境变量 ZYDOCK_DATA_DIR 指向任意目录。


【6】启动时会修改系统吗？

    只有「隐藏 Windows 任务栏」这一项（默认关闭）会调用系统 AppBar 接口
    把任务栏设为自动隐藏，不改注册表、不替换 Shell，退出时自动恢复原状态。
    「开机启动」默认关闭，只有你手动打开才写入当前用户的启动项。

    另外：Windows 的「任务栏自动隐藏」在部分版本上只是 AppBar 状态位生效、
    Explorer 实际不会收起任务栏。ZyDock 会直接测量任务栏窗口的真实位置来定位，
    所以无论任务栏是显示还是收起，Dock 都不会压在它上面。


【7】安全说明（本次加固后）

    · 程序不联网、无遥测、无自动更新、无第三方依赖（只用 .NET 8 + WPF 官方库）
    · 以普通用户权限运行（asInvoker），从不请求管理员
    · 注册表只在你打开"开机启动"时写一条 HKCU\...\Run，可随时关闭
    · 文件只写两个用户目录：%APPDATA%\ZyDock（配置）、%LOCALAPPDATA%\ZyDock\logs（日志）
    · 拖入图标只加入列表，不会自动执行；执行只发生在你点击时
    · 日志已脱敏，路径里的用户名替换成 %USERPROFILE%
    · 调试/自动化钩子只在 Debug 构建或显式开启自动化编译时才存在，
      正式发布版里没有任何可被外部消息驱动的代码路径
    · 未做数字签名，首次运行会出现 SmartScreen 提示，属正常现象
